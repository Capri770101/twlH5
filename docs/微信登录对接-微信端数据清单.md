# 微信登录对接 · 微信端数据清单

> 用途：跳舞兰 AI 花店 **H5 官网**接入「微信一键登录」。
> 面向：微信小程序平台 / 公众号负责人（微信端）。
> 原则：**H5 登录与微信内 JSAPI 支付共用同一个认证服务号**，一次配置两处生效。
> 说明：本文不含任何真实密钥，填好后请勿把 AppSecret 发到聊天群 / 提交仓库。

---

## 一、微信端需提供的数据（核心）

| # | 数据项 | 用途 | 获取位置（公众号后台） | 必填 | 备注 |
|---|--------|------|------------------------|------|------|
| 1 | **服务号 AppID** | 网页授权登录的唯一标识，拼进授权跳转链接 | 「设置与开发 → 基本配置 → 公众号开发信息」 | ✅ | 若与支付共用一个号，则直接填支付模块里的 `WXPAY_SP_APPID` 同值 |
| 2 | **服务号 AppSecret** | 后端拿 code 换 openid 的密钥 | 同上页面，点「重置」查看（仅显示一次） | ✅ | **机密**：仅存后端 .env，禁止进前端代码 / git / 聊天 |
| 3 | **公众号类型确认** | 能力前提 | 公众号后台「账号详情」 | ✅ | 必须是**认证服务号**（企业主体 + 已微信认证）。订阅号 / 未认证号**没有**网页授权能力 |
| 4 | **网页授权域名** | 授权回调必须在此域名下 | 「设置与开发 → 公众号设置 → 功能设置 → 网页授权域名」 | ✅ | 需 **ICP 备案域名、不带端口、不能是 IP**；配置时下载校验文件放到域名根目录验证 |
| 5 | **JS 接口安全域名** | 微信内调起 JS-SDK / WeixinJSBridge 支付 | 同一「功能设置」页面 | ✅ | 与第 4 项填同一个 H5 域名 |
| 6 | **接口 IP 白名单** | 公众号 access_token 等接口仅允许白名单 IP 调用 | 「设置与开发 → 基本配置 → IP 白名单」 | ✅ | 需加入 H5 后端服务器公网 IP **8.138.248.173**；如本机直连调试，再加本机出口 IP |

## 二、需微信端确认的决策项（决定实现方式，不一定是数据）

| # | 决策项 | 选项 | 建议 |
|---|--------|------|------|
| 7 | 登录用的公众号，是否与支付 JSAPI 用的 `WXPAY_SP_APPID` **同一个**？ | A. 同一个 B. 另开一个 | **强烈建议 A**：授权一次，登录 + 微信内支付共用，拿到的 openid 两处通用，不用二次授权 |
| 8 | 是否需要昵称 / 头像？ | A. 仅静默登录（snsapi_base，不弹窗，只拿 openid） B. 弹授权窗拿资料 | 建议 **A + 登录后引导用户自填**昵称/头像（前端已支持，Settings 页可改）。微信新规下 B 基本拿不到资料，还多一次弹窗。⚠️ 当前前端占位代码写的是 snsapi_userinfo（B 方案），按此决策需改成 snsapi_base |
| 9 | 是否要与**小程序用户体系打通**（认老用户 / 历史订单 / 会员）？ | A. 需要 B. 不需要 | 若 A：需提供**微信开放平台账号**（open.weixin.qq.com），并确认小程序 + 本公众号已绑定到**同一开放平台**（才能拿 unionid 跨端认人）。若 B：以手机号为主键归并即可，本项跳过 |
| 10 | 小程序 AppID（仅登记备查） | 填写 | ⚠️ 注意：H5 无法直接拿到小程序 openid，跨端认人只能靠 **unionid** 或**手机号**，给小程序 appid 本身不能用于 H5 登录 |

## 三、我方（H5 侧）前提，但微信端配置依赖它

| # | 项目 | 说明 |
|---|------|------|
| 11 | H5 **正式域名**（ICP 备案） | 第 4/5 项域名配置要填它；当前 `http://8.138.248.173:8088` 是验收环境，**IP + 非 443**，微信端一律不认 |
| 12 | **HTTPS 证书** | 网页授权、JSAPI 支付、支付回调全部强制 HTTPS |
| 13 | 授权回跳地址 redirect_uri | 形如 `https://<H5域名>/auth/wechat/callback`，域名为第 4 项；前端按此拼授权链接 |

## 四、H5 侧拿到数据后的落地位置（内部参考）

| 配置 | 放哪 | 内容 |
|------|------|------|
| 前端公开 appid | `src/mock/api.js` 的 `WX_APPID`（或 .env `VITE_WX_APPID`） | 服务号 AppID（appid 非机密，可进前端包） |
| 后端机密 | `server/.env`：`WXOAUTH_APPID` / `WXOAUTH_SECRET`（或复用 `WXPAY_SP_APPID` + 补 SECRET） | AppID / AppSecret（**已被 .gitignore 保护**） |
| 后端路由（待实现） | `server/src/auth-wechat.js` | ① 跳转授权 → ② code 换 openid → ③ users 表按 openid/unionid 查或建 → ④ 签发登录 token |
| 用户表 | `users` 表（模板已含 `openid / unionid / phone` 三列及唯一键） | 双轨登录无需改表；若要同存公众号+小程序 openid，拆 `gh_openid / mp_openid` 两列 |

## 五、安全红线（务必遵守）

1. **AppSecret 只允许出现在后端 .env**（已 gitignore），禁止进前端 bundle、git 历史、聊天记录。
2. 第 6 项 **IP 白名单务必配置**，避免 Secret 泄露后被异地机器盗调。
3. 正式上线前，微信登录 + 微信支付（JSAPI/H5）应**同一批域名 + HTTPS 一起联调**，共用一套公众号配置。
