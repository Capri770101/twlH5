设计说明 · 三处刻意的取舍
① 商品图用门店真实照片——花卉必须让用户预先看到实物，这是底线。代价是各店拍摄质量参差（背景杂乱、构图不一），所以统一套上「相纸白框 + 固定 1:1 居中裁切 + 淡色内描边」把参差原图规整成一致的图版；插画只保留在品牌位（报头、AI 入口、空状态、头像）；
② 金铜只出现在三处：花艺小助手的状态字、星级、优惠金额。它是"点"，不是"面"，铺开就腻了；
③ 券用票券形态（锯齿缺口 + 中央虚线），这是全站唯一允许"破坏网格"的元素——因为它天生就该像一张被撕下来的纸片。
v2 修订（2026-09-22）· 五处调整
① 商品图 → 门店真实商品照：48 处图位全部换成真实在售商品照（取自 10 家门店的 20 个不同商品），同时把商品名与价格对齐真实 SKU（例：向日葵图配「鲜花谢师恩 ¥88」、粉白玫瑰桶配「春风十里不如你 ¥88」），金额汇总（小计 / 满减 / 实付 / 购物车合计）已重算自洽；
② 登录页拆成两个状态：手机号 + 验证码 ／ 微信扫码（二维码图版 + 金铜角饰 + 5 分钟有效期与「改用手机号」出口）；
③ Tab 栏收敛为三项：首页 ／ 智能体 ／ 我的 —— 购物车不再占一级入口；
④ 购物车改为首页底部常挂胶囊：缩略图 + 件数角标 + 所属门店 + 合计金额 + 去结算，始终悬浮在 Tab 栏之上；
⑤ 设计感加强：Banner 文字叠层（真实花图压字）、图上角标（热销 / 新品）、图注编号（NO. / PL. / Fig.）、相纸内框、Tab 选中金铜短线。
v3 修订（2026-09-22）· 按钮与购物车
① 按钮改为 2px 小圆角：原先按钮/标签都是胶囊（999px），而全站所有"纸"（相纸框、印章、票券、图版）都是直角 —— 视觉上像两套系统。现在按钮收进直角语言，胶囊只留给筛选 chip 与状态药丸，各司其职；
② 按钮配色做成可切换主题：点顶部那排按钮即可切换全站配色（① 奶油白 / ② 柔粉 / ③ 鼠尾草 / ④ 杏桃，全部为明亮低饱和）。配色是成套的——商品详情操作条与首页购物车条一起变，不是孤立换一个按钮；
③ 购物车改为首页贴底整合条：不做悬浮挂件，而是与 Tab 栏连成一体（金铜顶线分隔），显示「购物车图标 + 件数角标 + 合计额 + 满减提示 + 去结算」。好处是任何滚动位置都能一键结算，且不再遮挡页面内容（悬浮挂件需要给页面底部留安全区）；
④ 主按钮加了层次：从纯平涂改为「上下渐变 + 描边」，在纸底上从"一块色"变成有体积的按钮。
v4 修订（2026-09-22）· 全部换成明亮系
反馈是「不要大红大绿的深暗色」，所以四套主题整体重做，主按钮与购物车条都不再出现深色块：
① 奶油白（默认）—— 暖白渐变按钮 + 墨绿字 + 金铜细边；购物车条用暖纸底 + 金铜顶线，去结算为浅鼠尾草绿
② 柔粉 —— 裸粉渐变 + 深棕字；购物车条为浅粉纸条
③ 鼠尾草 —— 浅绿渐变 + 墨绿字；购物车条为浅绿纸条（最贴"植物标本"主题）
④ 杏桃 —— 杏色渐变 + 深棕字；购物车条为米杏纸条
⑤ 连「AI 花艺顾问」入口块也一起提亮了——它原来是整页唯一的深绿渐变块，现在跟随主题变成浅色块 + 细边 + 墨绿字，页面上不再有任何深色窟窿。
四个主题的饱和度都压低了：底色在 #c0~#fd 的浅区间、文字统一用深墨绿或深棕（不用纯黑）， 这样既保住"能按"的明确度，又不会在暖纸底上砸出深色块。对比度靠细描边 + 轻投影来给，不靠压深底色。
