DISCIPLINE
五条纪律

这套风格的成败不在元素，在克制。评审时按这五条逐屏验收。

RULE 01朱砂 ≤ 4 处 / 屏

只出现在：价格、选中态、支付动作、日期/编号 kicker。红色一多就变促销页。

RULE 02发丝线是唯一分隔

1px #D5CCB9。禁用色块分区、禁用卡片投影、禁用渐变背景。

RULE 03圆角 ≤ 4px，阴影 = 0

器物感来自直角与细边框。实测观夏全站 border-radius 为空、box-shadow 为空。

RULE 04价格不嘶吼

ROSEONLY 实测：价格与商品名同色同字号。我们只给朱砂色，不加粗、不放大、不带感叹号。

RULE 05克制 ≠ 看不清

正文对比度 ≥ 4.5:1、大字 ≥ 3:1（WCAG AA）；最小字号 9px 仅用于角标，正文不小于 11px。文艺靠留白与字体，不靠把字调淡——本稿 660 处文字实测最低 4.94:1。落地时若有人想再调浅，先过这条。

与小程序共用：以上全部 token 同名写入 app.wxss（rpx 数值与 H5 的 rpx() 参数 1:1， 交接单 §7.4 已确认同尺度）。衬线字体小程序端 fallback 到系统宋体，无需引入字体文件。

RECOMMENDATION
我的推荐：v0.4 朱砂为全站基调，收编标本册的两件遗产

理由三条，都可验证：

WHY 01气质同宗，合并成本最低

标本册与 v0.4 都是「暖纸 + 宋体 + 发丝线」家族，差异只在主色（墨绿 vs 朱砂）与装饰密度。AI 页三处私有 token 收敛为全局 tokens 后，换主色是一次变量替换，不是重写。

WHY 02朱砂更贴品牌红

logo 采样里珊瑚红 #E04020 系是第二主色；朱砂 #93372B 是它的降饱和版，比墨绿离品牌更近，比金橙更高级。花是红色的生意，纸是白色的生意——朱砂落在纸上，才是花店。

WHY 03保留两件被验证的遗产

① 票券形态（券中心第 17 屏已采用）；② 「●◉○ 履约进度 + 来自门店」角标（订单详情第 14 屏已采用）。装饰纪律照搬 SPEC §6：印章≤3处、每屏≤1母题。

RISK风险与对策

朱砂在「促销感」上弱于金橙：大促期可用主题切换机制（标本册已验证 body class 换肤可行）临时挂 t-blush 柔粉主题，节后收回。日常态坚持朱砂 ≤4 处/屏。
