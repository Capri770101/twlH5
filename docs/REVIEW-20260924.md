# 2026-09-24 H5 联动交付

## 本批功能

- 账号隔离 DIY 保存与贺卡保存；DIY 保存而非直接购买。
- 结算页 AI 贺卡，最多五张、商品绑定、正文和预览图进入订单与商家同步。
- 语音录音/上传 → 转写 → 编辑后发送；自动播报开关记忆设置，关闭立即停止。
- 对话删除同步平台，历史本地保留卡片。

## 本轮审查修复

- 非流式 /chat 响应保留 data 的卡片与预览任务，避免 DIY 退化成普通购买卡。
- poll URL 幂等归一化；布尔 poll 使用 task_id；轮询容忍 429/5xx 并延长到后端任务期限。
- MySQL JSON 对象/字符串均能读取贺卡；服务端验证最多五张、正文与绑定商品。
- 开发代理默认 /api 和 /agent 使用现有 H5 网关，避免停用域名 404 和未启动本地后端 500。

## 验收

`npm run build`；浏览器检查录音取消/转写、播放开关、普通响应 DIY 卡、图片轮询和会话切换。
前序已验证真实 TTS WAV 播放链路，录音交互采用模拟设备验证；实体手机权限、真实订单/支付需要上线后专项验收。
播报优先简短 speech_text，缺失时读正文前 300 字；手机 HTTP 不能使用麦克风，可上传录音。
